# 🚗 Sistema de Gestão para Oficina Mecânica

Sistema web completo para gerenciamento de oficinas mecânicas, desenvolvido em PHP procedural com foco em controle operacional, organização administrativa e fluxo de serviços automotivos.

O projeto contempla módulos administrativos, recepção, mecânica, controle financeiro, estoque e emissão de relatórios, oferecendo uma estrutura robusta para gerenciamento interno da oficina.

## 🔍 Objetivo do Projeto

O principal objetivo do sistema é centralizar o gerenciamento operacional de oficinas mecânicas, facilitando:

* Controle administrativo
* Organização de serviços
* Gestão financeira
* Controle de estoque
* Acompanhamento de ordens de serviço

Além disso, o projeto também foi utilizado como estudo prático para evolução em arquitetura PHP e refatoração de sistemas legados.
